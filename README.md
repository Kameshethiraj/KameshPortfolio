# Kamesh E – Portfolio

Static portfolio site: `index.html`, `style.css`, and `script.js`. No build step.

The portfolio includes Projects, Stack, Experience, Education, Certificates, and Highlights sections. Update the content and certificate URLs in `index.html`; each certificate link is next to its entry in the Certificates section.

## Setup
1. Open `script.js` and replace the `YOUR-...` URLs in `LINKS` with your real GitHub, LinkedIn, LeetCode, and project links.
2. Open `index.html` in a browser to preview the site.

## Deploy on GitHub Pages
1. Create a repo (for a root URL, name it `<username>.github.io`).
2. Upload these files to the repo root and push.
3. Settings → Pages → Deploy from branch → `main` / root.
